How The 5 Algorithms Think

Start here if graph algorithms are new to you. Each card uses a small illustrative Mumbai journey so you can see the search process, not just read a definition. The examples are teaching simulations.

01 • UNINFORMED SEARCH

BFS — Breadth-First Search

LEVEL BY LEVEL

Simple idea: check all nearby options first, then move one layer farther out. Like ripples spreading through Mumbai.

Step 1

02 • UNINFORMED SEARCH

DFS — Depth-First Search

GO DEEP

Simple idea: pick one corridor and follow it deeply. If it does not work, backtrack and try another.

Step 1

03 • COST-BASED SEARCH

Uniform Cost Search

LOWEST COST

Simple idea: always expand the route with the smallest total distance travelled so far.

Step 1

04 • HEURISTIC SEARCH

Greedy Best-First Search

CHASE GOAL

Simple idea: look at the destination and choose the option that appears closest to it right now.

Step 1

05 • INFORMED SEARCH

A* Search

Simple idea: combine what we have already travelled with an estimate of what remains. It balances cost-so-far and smart lookahead.

f(n) = g(n) + h(n)

g(n) = distance already travelled
h(n) = estimated distance to the destination
